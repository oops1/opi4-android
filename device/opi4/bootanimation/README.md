# Boot animation

Original artwork in the Android 16 / Material 3 Expressive spirit, generated by
`make_bootanim.py` (Pillow + numpy). Roboto comes from AOSP `external/roboto-fonts`
(copy `font/3.011/Roboto-Regular.ttf` next to the script before running it).

* part0 (2.4 s, always played): a dot grows into a glowing blob, "android 16" fades in
* part1 (5 s loop until boot completes): cookie -> flower -> clover morph
* part2 (2.8 s, once after boot completes): blob turns into an orange, "android 16"
  flies towards the viewer, "Orange Pi 4" comes out of the dark

`python make_bootanim.py --preview-only` writes `preview.gif` only.
